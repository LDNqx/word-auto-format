## 🌟 项目简介

Word Auto Format 是一款智能的 Word 文档自动排版工具，通过 AI 技术自动识别文档结构并应用排版规则。只需用自然语言描述排版要求，即可一键完成整篇论文或文档的格式化。

### ✨ 核心特性

- 🤖 **AI 智能识别**：自动识别文档的语义结构（标题、正文、摘要、参考文献等）
- 💬 **自然语言输入**：用中文描述排版要求，无需记忆复杂的格式规则
- 🎨 **精准样式应用**：支持字体、字号、加粗、对齐、缩进等多种样式属性
- 📚 **学位论文优化**：针对中文学位论文结构进行优化，支持中英文双语内容
- ⚡ **即时应用**：在 Word 中实时预览和应用格式

### 🎯 适用场景

- 📖 学位论文格式化
- 📄 学术论文排版
- 📝 技术文档整理
- 📋 报告格式规范化
